# 🎙️ RAN — AI Radio

청취자의 사연과 뉴스, 음악 정보를 활용하여
**AI DJ가 라디오 대본을 생성하고 방송을 진행하는 생성형 AI 라디오 서비스**입니다.

## 📌 프로젝트 소개

RAN은 생성형 AI를 활용해 라디오 콘텐츠 제작 과정을 자동화하는 프로젝트입니다.

뉴스를 수집·요약하여 라디오 대본으로 변환하고, 청취자 사연의 감정을 분석해 공감 멘트와 음악을 추천합니다. 또한 날짜, 요일, 시간대와 입력 키워드에 맞는 오프닝과 클로징 멘트를 생성할 수 있습니다.

생성된 대본은 TTS(Text-to-Speech) 기술을 통해 AI DJ 음성으로 변환할 수 있습니다.

## ✨ 주요 기능

### 📰 뉴스 라디오

* 뉴스 콘텐츠 수집
* 뉴스 핵심 내용 요약
* 라디오 방송 형식의 뉴스 대본 생성
* 주요 뉴스 및 추가 뉴스 구성

### 💌 사연 라디오

* 청취자 사연 분석
* 사연의 주제와 감정 파악
* AI DJ의 공감 멘트 생성
* 방송에 사용할 사연 자동 선별

### 🎵 음악 라디오

* 분위기와 감정에 맞는 음악 추천
* 장르 및 아티스트 기반 음악 소개
* 음악의 배경과 트렌드를 반영한 DJ 멘트 생성

### 🚗 교통 라디오

실시간 교통정보를 분석하여 운전자에게 필요한 내용을 AI DJ 형식으로 전달합니다.

* 지역별 교통상황 및 도로 정보 확인
* 정체 구간과 사고 구간 안내
* 출발지와 목적지에 따른 교통정보 제공
* 교통정보를 자연스러운 라디오 대본으로 변환
* 시간대와 도로 상황에 맞는 안전운전 안내 멘트 생성
* 생성된 교통 대본을 AI DJ 음성으로 변환

### 🎤 오프닝·클로징 생성

* 날짜와 요일을 반영한 멘트 생성
* 시간대에 적합한 인사말 생성
* 입력 키워드에 맞는 방송 오프닝 및 클로징 구성

### 🔊 AI DJ 음성

* 생성된 라디오 대본을 TTS 음성으로 변환
* 실제 라디오처럼 자연스러운 AI DJ 방송 제작

## 📂 프로젝트 구조

```text
AI_radio
├── backend
│   ├── app          # 오프닝·클로징 생성
│   ├── common       # 공통 기능 및 프롬프트 처리
│   ├── music        # 음악 라디오 생성
│   ├── news         # 뉴스 수집·요약 및 대본 생성
│   ├── story        # 청취자 사연 분석 및 대본 생성
│   └── main.py      # 백엔드 실행 파일
│
├── frontend         # 사용자 화면
├── .gitignore
└── README.md
```

## 🔐 환경변수 설정

API 키와 같은 중요한 정보는 `.env` 파일에 저장합니다.

```env
API_KEY=your_api_key
```

`.env` 파일은 개인정보와 API 키 보호를 위해 GitHub에 업로드하지 않습니다.
